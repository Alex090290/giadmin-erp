# Exportar colecciones a Excel

Pendiente futuro acordado el 2026-11-15; no implementado ni incluido en la ampliación
actual de compute en colecciones.

Ofrecer Exportar respetando permisos, reglas por registro, filtros y columnas
publicadas del servidor. Incluir compute usando el mismo núcleo autorizado;
para todo el conjunto filtrado recorrer páginas en servidor, no sólo la visible.
Diseñar límites de tamaño/tiempo, selección frente a conjunto completo, consistencia
del snapshot y salida segura de celdas. Elegir biblioteca/descarga cuando se retome.
No exportar campos ocultos por política ni permitir al navegador elegir modelos,
delegates o rutas arbitrarias. No hay API, botón ni formato definitivo todavía.
